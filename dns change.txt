1. Change DNS on Windows
Open Network Connections:

Press Windows + R, type ncpa.cpl, and press Enter.
This will open the Network Connections window.
Choose Your Network Adapter:

Right-click on the active network connection (Ethernet or Wi-Fi).
Select Properties.
Select IPv4:

In the Networking tab, scroll down and select Internet Protocol Version 4 (TCP/IPv4).
Click on Properties.
Change DNS:

Select the option Use the following DNS server addresses.
Enter the new DNS addresses (for Google's DNS):
Preferred DNS server: 8.8.8.8
Alternate DNS server: 8.8.4.4
Click OK to save the changes.
Restart the Connection:

After making the changes, disconnect and reconnect your network to apply the new DNS.
